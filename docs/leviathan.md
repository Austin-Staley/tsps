# Leviathan encounter design

The post-quest Leviathan is a members-only owner-scoped encounter, entered through the Scar's rowboat and arena handholds after Desert Treasure II. The existing quest encounter remains untouched. Its 7x8 cache-template layout (chunks257,792, planes0 and1) supplies the bridge-correct arena, not a behavioral oracle for its simplified attacks.

Sources: [Leviathan](https://oldschool.runescape.wiki/w/The_Leviathan), [Strategies](https://oldschool.runescape.wiki/w/The_Leviathan/Strategies), [Perfect Leviathan](https://oldschool.runescape.wiki/w/Perfect_Leviathan); local revision241 cache gamevals are authoritative for NPC, loc, sequence, projectile, graphic and varp IDs. Public RSProx NPC12214 search found recordings555,550,100,1750,1754,1751 (LeaguesV) and3285,788 (GridMaster). Their modified stats/loot are not normal or awakened balance evidence. Another private server is not used as an oracle.

Normal mechanics: 900HP; impact-prayer orbs (magic32, ranged24, melee50), adjacent bite50, seven progressively faster volley tiers, avoidable debris and unavoidable roar chip; shadow spells always stun outside enrage, front hits capped10, ranged rear punishment and doubled magic rear damage; alternating lightning and smoke specials, with33% damage reduction during specials;20% enrage with a clockwise moving5x5 pathfinder buff, ranged perfect accuracy/minimum20%-max hit, doubled magic and prayer piercing outside its aura. Stuns do not stop enrage. Smoke already in progress must finish on enrage. Perfect grades exclude roar chip and freeze at lethal boss damage, using actual applied player damage through shared prerequisite#882.

Awakened scaffolding uses2700HP, stronger canonical stats, shortened stun, five-block cross debris, one-tick enrage,7x7 aura and a pursuing tornado below50%HP. **Awakened entry is disabled and never consumes an orb.** The Wiki gives only lower bounds for tornado and awakened smoke damage, and does not resolve half-tick stun rounding. These values must be verified before enabling this mode. Shared stat-drain immunity, grave fee provenance and Slayer target eligibility are prerequisites.

This is a functional normal-mode implementation, not a claim of measured OSRS parity. The Wiki does not specify the volley length, early projectile flight times, first-attack/roar delays, lightning duration/maximum damage, respawn delay, pathfinder movement interval or detailed visual/tail placement. Provisional values live in the authored data and Model; current lightning maximum30 is provisional. The tests verify the mechanics and lifecycle against those explicit choices. First-hand normal-world observation is still needed to replace these assumptions; Leagues/GridMaster captures cannot establish unmodified balance. No alternative private server was used to fill these gaps.

Lifecycle: reject incomplete quests; consume an Awakener's orb only after a current-state confirmation; create one private session per owner; reset fights on respawn; clean all hazards/NPCs on exit, teleport, death and logout; recover persisted inside flags to a public Scar tile. Death items follow normal gravestones outside by the rowboat. Reduced fees before five normal kills require a shared gravestone provenance modifier, coordinated with the parent task rather than patched locally. Counts and PBs are separate for normal/awakened, persisted, and reported through existing achievement hooks. Canonical NpcDrops owns loot; this plugin only answers context and accessible loot placement. No copied drop table or manual generated-data edits.

Plugin units: Common (API/cache/data/damage), Model (geometry and deterministic volley state), Site (access/session/instance), Fight (lifecycle/hits/stuns/enrage), Hazards (debris/lightning/smoke/pathfinder/tornado), Rewards (counts/PBs/achievement/context/loot location). All content remains under bosses/leviathan with authored balance/timing data under bosses/data. Carried unprotected items use the outside grave; pre-existing floor loot is lost on instance destruction, as documented on the boss Wiki page.

The existing quest-only Scar stone handler stops after quest completion. This plugin handles the two revision241 Stepping Stone objects at2031/2033,6430 after completion, crossing directly between walkable shores2029/2035. The intermediate hopping animation is not capture-verified. The public grave/recovery tile2063,6435 and Guardian arrival2021,6433 are checked against actual cache collision; the originally proposed2064,6435 is blocked and is not used.

The pathfinder follow-up replaces monotonic greedy movement with a deterministic search bounded by the arena floor. It can take a detour around debris even when the first step does not reduce distance, checks directional cache clipping and both orthogonal neighbors for diagonals, and stays stationary if no route exists. This is a collision-safe correction, not a claim that its tie-breaking reproduces an uncaptured OSRS route. Clockwise corner order and the authored movement interval are retained. Aura buffs and prayer piercing follow actual NPC registration, without the former extra two-tick activation delay; movement starts one existing interval after registration is observed. This follows the Wiki's 16 August 2023 protection-until-spawn change without inventing an exact spawn delay. Unregistered NPCs neither move nor grant effects.

Validation uses a real revision241 cache, Player/NPC, templated bridge clipping, HitQueue and NPCDeathTask. All 37 focused tests pass. The complete server suite passes 4,987 tests with zero failures or skips under `--test-concurrency=4`; the TypeScript build also passes. They cover impact protection and actual damage grading, shadow spell IDs/front/rear damage, both specials and smoke continuing through enrage, aura/cadence, death freeze, canonical conditional loot, count/PB/achievement events, repeat kills, quest gating, graves and logout recovery. The generic combat-achievement NPC-death handler counts kills; the encounter does not emit a duplicate manual kill event. Run from `server`: `node node_modules/typescript/bin/tsc --build`, then `node --test tests/leviathan-*.test.cjs` (expand the wildcard on shells that do not).
